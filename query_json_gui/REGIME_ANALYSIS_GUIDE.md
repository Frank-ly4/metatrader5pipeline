# Regime Analysis Feature - User Guide

## What It Does

The **"Backtest this parameter set…"** button now performs **regime-based performance analysis**:

1. Takes a promising parameter set from your optimization results
2. Runs a backtest using your **existing 4.2.5 backtest engine** (bands_v2 strategy)
3. Loads chart analysis (regime segments) from `outputs/analyses/`
4. Tags each trade by regime (trend_up_high_vol, trend_down_low_vol, etc.)
5. Shows you detailed breakdown: trades per regime, win rates, PnL, top/worst trades

## Why This Is Better

### ✅ Uses Your Proven 4.2.5 Code
- Same backtest engine as optimizer
- Same bands_v2 strategy
- No duplication or confusion

### ✅ No Mass Trade Storage
- Trades only saved when YOU analyze a specific trial
- Not stored during optimization (keeps JSON files manageable)

### ✅ Regime Insights
- See which market conditions your strategy wins/loses in
- Identify if strategy works in specific trends
- Understand trade distribution across regimes

## How to Use

### Step 1: Load Optimization Results

```
1. Open Query GUI (run_simple.bat)
2. Click "Load Folder"
3. Select: 4.2.5/outputs/runs
4. Results load with default filters applied
```

### Step 2: Find Promising Parameter Set

```
1. Sort by calmar_ratio (click column header)
2. Review metrics (sharpe, drawdown, trades)
3. Select a row you want to analyze deeper
```

### Step 3: Run Regime Analysis

```
1. Click "Backtest this parameter set…"
2. Dialog opens showing:
   - Trial UID
   - Chart name
   - Fold ID
3. Configure backtest:
   - Starting Capital: e.g., 10000
   - Fees (%): e.g., 0.1 for 0.1%
   - Max Concurrent Positions: e.g., 3
4. Click "Run Backtest"
```

### Step 4: View Results

```
Report shows:
- Overall Performance (return, sharpe, sortino, calmar, etc.)
- Breakdown by Regime:
  - Trades per regime
  - Win rate per regime
  - Total PnL per regime
  - Top 3 and Worst 3 trades per regime
```

### Step 5: Save Report (Optional)

```
1. Click "Save Report..." in report dialog
2. Choose filename (includes Trial UID)
3. Report saved as text file for future reference
```

## File Locations

### Charts
- **Location:** `4.2.5/data/active_charts/`
- **Format:** CSV files (XAUUSD_1h_cl_3.csv, etc.)
- **Used by:** Backtest engine

### Chart Analyses
- **Location:** `4.2.5/outputs/analyses/`
- **Format:** JSON files (XAUUSD_1h_cl_3.json, etc.)
- **Contains:** Regime segments, trend/vol distribution
- **Generated by:** `python scripts/chart_analyzer.py`

### Optimization Results
- **Location:** `4.2.5/outputs/runs/`
- **Format:** JSON files with trial results
- **Loaded by:** Query GUI

### Regime Analysis Script
- **Location:** `4.2.5/scripts/run_regime_analysis.py`
- **Called by:** Query GUI "Backtest this parameter set" button
- **Outputs:** JSON with regime breakdown to stdout

## Prerequisites

### 1. Chart Analysis Must Be Run First

Before regime analysis will show regime breakdown, you need chart analysis files:

```bash
cd 4.2.5
python scripts/chart_analyzer.py --chart XAUUSD_1h_cl_3.csv --save-analysis
```

**OR** run analyzer on all active charts:

```bash
python scripts/chart_analyzer.py --all --save-analysis
```

### 2. Results Without Chart Analysis

If chart analysis file doesn't exist, the report will show:

```
REGIME BREAKDOWN: Not Available

Chart analysis file not found. Run chart analyzer first:
  python scripts/chart_analyzer.py --chart XAUUSD_1h_cl_3.csv --save-analysis
```

You'll still get:
- Overall performance metrics
- Trade count and basic stats
- But trades won't be tagged by regime

## Technical Details

### How Regime Tagging Works

1. **Trade Entry Time:** When trade enters (e.g., 2025-04-09 10:00:00)
2. **Chart Segments:** Loaded from analysis JSON
3. **Time Matching:** Find segment where trade entry falls
4. **Tag Applied:** Trade tagged with segment's regime

### Example Segment:
```json
{
  "start": "2025-04-09 10:00:00",
  "end": "2025-04-14 13:00:00",
  "bars": 124,
  "regime": "trend_up_high_vol",
  "return_pct": 5.73
}
```

### Regime Types

Format: `{trend}_{volatility}`

**Trends:**
- `trend_up` - Upward momentum
- `trend_down` - Downward momentum
- `range` - Sideways/ranging

**Volatility:**
- `high_vol` - High volatility
- `mid_vol` - Medium volatility
- `low_vol` - Low volatility

**Examples:**
- `trend_up_high_vol` - Strong uptrend with high volatility
- `trend_down_low_vol` - Downtrend with low volatility
- `range_mid_vol` - Ranging market with medium volatility

## Troubleshooting

### "Script Not Found" Error

**Problem:** Can't find `run_regime_analysis.py`

**Solution:**
1. Make sure you loaded from `4.2.5/outputs/runs` folder
2. Check script exists at `4.2.5/scripts/run_regime_analysis.py`
3. Verify folder structure is intact

### "Chart Not Found" Error

**Problem:** Can't find chart file

**Solution:**
1. Check `4.2.5/data/active_charts/` contains the chart
2. Verify chart name matches exactly (case-sensitive)
3. Make sure CSV file exists (not just .parquet)

### "Regime analysis timed out"

**Problem:** Analysis took >5 minutes

**Reasons:**
- Very long chart (many bars)
- Heavy computation in strategy
- System under load

**Solutions:**
- Try analyzing shorter charts first
- Close other programs
- Check if strategy has infinite loops

### No Regime Breakdown Shown

**Problem:** Report shows "Not Available"

**Solution:** Run chart analyzer first:
```bash
python scripts/chart_analyzer.py --chart XAUUSD_1h_cl_3.csv --save-analysis
```

## FAQ

**Q: Does this re-run the entire optimization?**
A: No. It only runs ONE backtest for the selected trial. Fast and focused.

**Q: Will this create thousands of trade records?**
A: No. Trades only exist in-memory during analysis and in the report if you save it. Optimizer JSON files unchanged.

**Q: Can I analyze multiple folds at once?**
A: Currently, no. Analyze one fold at a time for clarity. You can run multiple analyses and compare reports.

**Q: What fees should I use?**
A: For XAUUSD on MetaTrader 5, typical fees are 0.05-0.1% per trade. Research your broker's specific fee structure.

**Q: Does this work with v1 strategy?**
A: No. It's hard-coded to use `bands_v2`. If you need v1, modify `run_regime_analysis.py` line 172.

**Q: Can I run this from command line?**
A: Yes!
```bash
cd 4.2.5
python scripts/run_regime_analysis.py --uid 20251018_112307:28 --capital 10000 --fees 0.001
```
